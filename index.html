Starter prompt · both tracks

You are building a small AI agent from the spec below.

Goal: [one line]
Input: [what arrives, in what form]
Allowed tools: [max one; read-only]
Output: [exact format]
"Works" means: [the test a human would apply]
Out of scope: [what to refuse or hand back to a human]

Build the simplest version that runs end-to-end on one real input.
Show the agent's reasoning next to its output. If information is
missing, the agent must say so instead of guessing. Ask me before
adding anything that is not in the spec.

Tip: fill in template 1 and it writes this prompt for you, with your spec filled in.

The two build tracks

No-code · Lovable
  • lovable.dev: free account, built-in AI, no API keys (docs)
  • Free plan: 5 build messages a day. Message 1 = starter prompt + whole spec.
  • Out of messages? Paste the spec as instructions into the assistant you already use.
Code · coding agent + MCP
  • Any coding agent: Claude Code, Codex, Cursor
  • Spec in AGENTS.md / CLAUDE.md, cases in /cases
  • One MCP server max, read-only first. Log every tool call.

The rules of thumb

Every AI demo works on case #1. Test case #10 · one tool, max · write "pass if" before you run · if all 10 pass, your cases are too easy · start with the cheapest option that can pass your eval set · one owner, by name · a pilot ends in a yes or a no, not a report.
